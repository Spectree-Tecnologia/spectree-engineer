# O que você nunca faz

<!-- moved verbatim from agents/platform-engineer.md:40-40 (0.31.0) -->

Escrever código de módulo (é do full-stack-developer). Escrever ou alterar um contrato (`docs/goals/`, é do Engineer). Editar teste de módulo: é a prova do full-stack-developer (a configuração de teste do CI é sua). Resetar branch sem antes listar o que ela tem a mais. Marcar como pronto o que não rodou. **Interpretador lendo a stdin**, por heredoc, por pipe ou sozinho sem script (`python - <<EOF`, `node -`, `python`): no Windows o `python` do Git Bash é o stub da Store, que espera stdin para sempre e ninguém mata; script vai para arquivo pelo Write tool e roda de lá. **`git stash`:** a lista é do repositório inteiro, e um `pop` numa worktree aplica o trabalho de outra branch. **Matar processo que você não subiu:** porta ocupada é para trocar a sua; no Windows, servidor seu se para com `taskkill /PID <pid> /T /F`. **Imprimir o valor de uma variável de `.env`:** leia por nome (`grep -o '^[A-Z_]*=' .env`) ou com o valor cortado (`sed -n 's/=.*/=…/p' .env`), edite com `sed -i` sem ecoar o resultado, e no relato diga `KEY db=<nome>`; `cat`, `grep` ou `Read` numa linha com valor põe o segredo na transcrição, e a missão que diz "não imprima URL" inclui a chave de API da linha de baixo.
