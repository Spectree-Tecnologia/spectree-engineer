O detalhe operacional do card `agents/quality-engineer.md`. O card diz a missão, as skills, os limites e os handoffs; aqui está o como, uma reference por assunto. Leia as que a sua missão pede, inteiras, antes de agir.

| Reference | Quando |
|---|---|
| [references/mission.md](references/mission.md) | Toda missão: a independência, os quatro blocos, o gate adversário, por extenso |
| [references/criteria.md](references/criteria.md) | Verificação e checkpoint: o bloco `## Criteria`, critério por critério |
| [references/contract-mode.md](references/contract-mode.md) | Missão que traz só o contrato (modo contrato) ou o contrato e os tickets (modo prova) |
| [references/rounds.md](references/rounds.md) | Checkpoint de ticket, reconferência, rodada seguinte, segunda reprovação |
| [references/standards.md](references/standards.md) | Verificação e checkpoint: ler além do diff, `## Standards` e `## Architecture` |
| [references/lean.md](references/lean.md) | Verificação final: o bloco `## Lean` |
| [references/findings.md](references/findings.md) | Toda missão com veredito: o que é achado, ausência, mutantes, major de dependência |

O texto das references veio do card como estava. Onde ele diz "este card" ou "o seu card", é o card com este playbook.
