# Controller Pattern

## Reference paths

- Controllers: `apps/backend/src/modules/<m>/<m>.controller.ts` (`config-new-module` generates the first one).
- Security (generated by `config-shared-backend`):
  - `apps/backend/src/shared/auth/jwt.guard.ts` — `JwtGuard`, registered as `APP_GUARD`: every route closed by default
  - `apps/backend/src/shared/decorators/public.decorator.ts` — `@Public()` opens a route
  - `apps/backend/src/shared/decorators/current-user.decorator.ts` — `@CurrentUser()` / `@CurrentUser('id')`
  - `apps/backend/src/shared/errors/api-exception.filter.ts` — single error envelope

## Role of the controller

- Convert the HTTP request into input for the use case.
- Control authentication/authorization and the HTTP status.
- Translate the domain's `Result` into a response or a Nest exception.

## Implementation checklist

- [ ] `@Controller('base-route')` defined.
- [ ] Correct HTTP method decorators (`@Get`, `@Post`, `@Patch`, `@Delete`).
- [ ] `@Public()` only on a really open route; `userId` always from `@CurrentUser('id')`.
- [ ] Inputs extracted via `@Body/@Param/@Query`.
- [ ] Basic type normalization done in the controller (page/pageSize/bool string).
- [ ] Failures mapped to consistent HTTP exceptions:
  - `BadRequestException` (400)
  - `UnauthorizedException` (401)
  - `NotFoundException` (404)
  - `InternalServerErrorException` (500)
- [ ] The final response follows the endpoint's contract (payload, empty, 201/204 etc.).

## Patterns observed in the code

- The controller instantiates/calls the use case and does not execute domain rules.
- No per-controller `@UseGuards`: the JWT guard is global; role permission, when the project has it, comes in as its own guard on top of `@CurrentUser()`.
- Paginated listings receive `page/pageSize` as a query string and parse them.

## Common pitfalls

- Putting domain rules in the controller.
- Coupling the controller to unnecessary infrastructure details.
- Not normalizing numeric/boolean query params.
- Exposing a raw error without the `errors` envelope when the module's pattern requires it.
